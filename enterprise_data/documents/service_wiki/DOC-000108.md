## Overview

reporting-service is a tier-2 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/reporting-service.

## Ownership

## Technology Stack

reporting-service is written in Go, stores data in Cassandra and publishes events through Azure Service Bus.

## Reliability Targets

The availability SLO for reporting-service is 99.99 percent and the p95 latency target is 200 ms.
