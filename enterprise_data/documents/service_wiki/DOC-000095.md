## Overview

inventory-engine is a tier-2 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/inventory-engine.

## Ownership

## Technology Stack

inventory-engine is written in Go, stores data in Cassandra and publishes events through Azure Service Bus.

## Reliability Targets

The availability SLO for inventory-engine is 99.5 percent and the p95 latency target is 600 ms.

## Dependencies

inventory-engine depends on: shipping-service, ledger-service, auth-api.
