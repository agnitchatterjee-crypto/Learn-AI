profile-engine is a tier-1 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/profile-engine.

## Technology Stack

profile-engine is written in Node.js, stores data in DynamoDB and publishes events through Azure Service Bus.
