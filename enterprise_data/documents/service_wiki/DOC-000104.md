## Overview

profile-sync is a tier-2 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/profile-sync.

## Technology Stack

profile-sync is written in Java, stores data in MySQL and publishes events through Amazon SQS.

## Reliability Targets

The availability SLO for profile-sync is 99.95 percent and the p95 latency target is 300 ms.

## Dependencies

profile-sync depends on: ingestion-gateway, recommendation-sync, ledger-gateway.
