## Overview

payments-api is a tier-3 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/payments-api.

## Ownership

payments-api is owned by Layla Joshi in Engineering.

## Technology Stack

payments-api is written in Node.js, stores data in PostgreSQL and publishes events through RabbitMQ.

## Reliability Targets

The availability SLO for payments-api is 99.9 percent and the p95 latency target is 600 ms.
