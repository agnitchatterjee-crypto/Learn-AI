## Overview

reporting-gateway is a tier-3 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/reporting-gateway.

## Ownership

reporting-gateway is owned by Pooja Gupta in Engineering.

## Technology Stack

reporting-gateway is written in Kotlin, stores data in MongoDB and publishes events through Azure Service Bus.

## Reliability Targets

The availability SLO for reporting-gateway is 99.9 percent and the p95 latency target is 900 ms.
