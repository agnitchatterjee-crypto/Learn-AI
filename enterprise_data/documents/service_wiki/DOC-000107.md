## Overview

ledger-gateway is a tier-1 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/ledger-gateway.

## Ownership

ledger-gateway is owned by Ava Tan in Engineering.

## Technology Stack

ledger-gateway is written in Java, stores data in DynamoDB and publishes events through Kafka.
