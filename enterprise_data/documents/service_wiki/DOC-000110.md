## Overview

auth-api is a tier-2 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/auth-api.

## Ownership

auth-api is owned by Mei Becker in Engineering.

## Technology Stack

auth-api is written in Java, stores data in DynamoDB and publishes events through Amazon SQS.

## Reliability Targets

The availability SLO for auth-api is 99.99 percent and the p95 latency target is 450 ms.

## Dependencies

auth-api depends on: search-sync, inventory-engine, payments-api.
