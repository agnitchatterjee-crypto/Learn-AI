## Overview

ledger-sync is a tier-1 backend component of the Northwind Analytics platform. Source code lives at https://git.northwind-analytics.example.com/platform/ledger-sync.

## Ownership

ledger-sync is owned by William Becker in Engineering.

## Technology Stack

ledger-sync is written in Node.js, stores data in MongoDB and publishes events through Amazon SQS.

## Reliability Targets

The availability SLO for ledger-sync is 99.9 percent and the p95 latency target is 80 ms.
