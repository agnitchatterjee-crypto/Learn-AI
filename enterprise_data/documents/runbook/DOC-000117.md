## Alert

This runbook covers the 'Disk usage high' alert for analytics-engine. Trigger threshold: 90 (see monitoring dashboard).

## Triage

1. Check the dashboard for analytics-engine. 2. Review recent deployments. 3. Post updates in #oncall-analytics-engine.

## Mitigation

If the alert persists, restart the service with: kubectl rollout restart deployment/analytics-engine
