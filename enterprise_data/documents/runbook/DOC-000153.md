## Alert

This runbook covers the 'Disk usage high' alert for profile-engine. Trigger threshold: 80 (see monitoring dashboard).

## Triage

1. Check the dashboard for profile-engine. 2. Review recent deployments. 3. Post updates in #oncall-profile-engine.

## Mitigation

If the alert persists, restart the service with: kubectl rollout restart deployment/profile-engine

## Escalation

If the 'Disk usage high' alert is not resolved within 15 minutes, page the secondary on-call engineer.
