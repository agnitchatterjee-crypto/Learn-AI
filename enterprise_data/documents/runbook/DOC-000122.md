## Alert

This runbook covers the 'Queue backlog' alert for search-sync. Trigger threshold: 2 (see monitoring dashboard).

## Triage

1. Check the dashboard for search-sync. 2. Review recent deployments. 3. Post updates in #oncall-search-sync.

## Mitigation

If the alert persists, restart the service with: kubectl rollout restart deployment/search-sync
